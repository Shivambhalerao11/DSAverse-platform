# PROJECT NAME

DSAverse – The Next Generation Interactive Data Structures & Algorithms Learning Platform

Tagline:
**Visualize. Play. Master DSA.**

---

# ROLE

Act as a world-class Product Designer, UX Architect, UI Designer, EdTech Expert, Game UX Designer, and Senior Full-Stack Product Designer with 20+ years of experience designing products for Apple, Google, Stripe, Linear, Duolingo, Brilliant.org, Figma, Framer, and top EdTech companies.

Your task is to design a complete production-ready Figma UI/UX for a modern Data Structures & Algorithms learning platform.

This should NOT look like LeetCode, GeeksForGeeks, HackerRank, or any traditional educational website.

The goal is to create the world's most engaging DSA learning experience where students learn through interactive visualizations, simulations, games, and animations while teachers can easily teach using the same visual tools.

---

# PRODUCT VISION

Students should never feel like they are reading a textbook.

Instead, they should feel like they are entering an interactive digital world where every Data Structure becomes alive.

The website should feel like a premium SaaS platform until a student opens a learning module.

Once a learning module is opened, the interface should transform into a beautiful interactive learning experience with game mechanics.

The experience should make students say:

"I have never seen DSA taught like this before."

# FINAL GOAL

Create a complete Figma design that feels like a premium commercial product rather than a college project.

The website should have two personalities:

1. A professional SaaS platform for authentication, dashboards, teachers, and navigation.

2. An immersive, interactive learning world that begins when a student opens Array, Tree, String, Stack, Queue, Linked List, Graph, or any other DSA topic.

Every learning world must be fully visual, intuitive, and engaging so students can learn by interacting with the concepts instead of memorizing theory.

The final UI/UX should be polished enough that it could realistically become the interface for a globally recognized EdTech platform.
